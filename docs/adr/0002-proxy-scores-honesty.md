# ADR 0002：没有客户数据时，双模型分数用"代理评分"并明说

日期：2026-11-08
状态：已实施

## 背景

演示的核心冲突是"baseline（开箱即用 embedding）vs 微调后"。但当前**没有客户数据、
也还没跑真微调**——两个模型的分数从哪来？三条路：

1. 等真模型跑完再演示（周期不可控）；
2. 随便编两个数字（演示会显得超自然，客户一问口径就穿帮）；
3. **代理评分**：规则可解释的评分器模拟两个模型的行为差异，口径写进页面脚注。

## 决策

选 3，且遵守三条诚实红线（页面 footer 已声明 SYNTHETIC DATA）：

### 评分语义

- **baseline** = 字面相似度加权（`FIELD_WEIGHTS`：name 0.42 / id 0.25 / dob 0.18 /
  pob 0.10 / phone 0.05，缺字段自动重归一）。跨文字名字对它返回 0.12——
  这是"开箱 embedding 对中↔拉丁近盲"的代理，不是 bug。
- **tuned** = `0.30·base + 0.70·oracle`。oracle 不是满分：
  - 同实体：有**佐证**（证件号 ≥0.5 吻合 / 电话相同 / 生日+籍贯全同）才给 0.90；
    曾用名型（字面 <0.13 且无佐证）封顶 0.50——微调也接不上；
  - 相似实体（lookalike）：0.28——"学会了像 ≠ 是"；
  - 无关：压到 base 的 55%。

### 剧本钉死 vs 公式涌现

只有 4 对关键案例分数被 `SCRIPTED_OVERRIDES` 钉死（Q2 音译、Q4 同名、Q5 双胞胎、
Q6 曾用名），保证 Arena/Explain 的叙事是教科书走向；**其余所有对由公式涌现**，
指标是对全量 47 条记录算的，不是挑出来的。钉死的 4 对有测试逐个锁定数值。

### 诚实失手

Q6（Victor Chen ↔ 陈志强）**故意让微调也失败**：零表面重合、无佐证，
0.48 不过 0.55 的线。演示时明说"这是代理评分器的天花板，真模型的价值恰恰在
这种案例上"——给真模型留出超越空间，也让故事可信。

## 指标口径（写进 Scoreboard 脚注）

每条记录作为查询、检索其余记录取 top-5；hit = ground truth 同实体；
断言 = top-5 内 score ≥ θ(0.55)。

- **recall@5**：top-5 命中率（找回能力）；
- **link_recall**：被断言的真链路 ÷ 全部真链路（敢连的能力）；
- **link_precision**：断言里对的占比；
- **false_link_rate**：相似实体查询中断言了影子人的占比（仅 similar_entity 场景）。

四个指标各答一个问题，防止"一个数字赢麻了"式的演示。

## 换真模型的接入点

数据契约不变：`data/results.json`（{model: {qid: top-5}}）+ `data/metrics.json`
换成真跑分产物即可，页面零改动。代理评分层（`simulate.py`）届时整体退役。
