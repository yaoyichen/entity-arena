# ADR 0003：落地页重构——hero 双栏 + 三态动画预览卡 + 单一英雄数字

日期：2026-11-18
状态：已实施（f2b644e）

## 背景

旧落地页是"等大卡片墙"：开场数字带（四格等大 tile）→ 三步叙事卡 → 双轨卡 →
六视图导览，八块内容权重相同。给客户演示时的反馈是"说不出来什么感觉，但是
重点不突出、也不够高级"。诊断出三个根因：

1. **没有视觉落点**——四格等大 tile 把最重要的结论（微调后零误连）和数据规模、
   战绩摆成平级，视线无处落；
2. **满屏静态**——第一屏没有任何会动的东西，"网络三态"这个核心叙事要切到
   Network 视图才能看到；
3. **导航重复**——六视图导览网格和顶栏 nav 完全重复，稀释密度却不增信息。

## 决策

第一屏改为一条明确的动线，每层只有一个主角：

```
hero 标题（问题）→ 动画卡（过程）→ 英雄数字（结论）→ 时间线（怎么讲）→ 双轨 chips（数据可信度）
```

- **hero 双栏**：左侧疑问式大标题 + 双 CTA（"跟着走一遍"看懂型 / "跳到试玩台"
  上手型，分流两类客户）；右侧**三态动画预览卡**——迷你网络图自动轮播
  原始纠缠 → 基线误连（红）→ 微调归并（青光环），caption 带阶段名 + 进度点，
  **整卡点击直达网络视图当前阶段**（动线闭环）。全页唯一会动的元素，
  把 Network 视图的核心叙事压缩成 ~13 秒预告片；
- **英雄数字带**：只留一个主数字（微调后误连数），其余三个指标降为注脚行，
  上下细线一夹。主数字文案**复用租户可覆盖键**（`home.st.tuned.*`）——
  租户构建零改动继续个性化，不新增契约面；
- **三步时间线**替代大段文案卡（圆点 + 连接线 + 短标题 + mono chip），
  **双轨 chips** 替代两张等大轨道卡；六视图导览网格删除（顶栏已有）。

## 实施要点

- 迷你图是**独立渲染器**（`buildMiniNet()`），不与主 netbox 共享全局；
  `setLang`/切轨会重跑 `renderHome`，故必须幂等且先 `miniNet.stop()` 取消旧
  rAF；循环仅在 home 视图激活时推进。
- 小卡元素按"等重加强"校准：迷你边 .95/1.4（主视图 .78/1.6，小尺寸需更重
  描边才等重）、节点用亮阶 token `--node-hi`、光环描边 .95/1.9——色相与主视图
  `.halo` 同族，不另起炉灶。
- 首屏 900px 视口内收完（实测 854px），折痕不切半块内容。

## 验证方法（可复用）

截图验证动画卡时，**不要用固定延时等待**——工具链单步开销（5–15s）远超阶段
窗口（3.6s），两次把 stage-1 截成"caption 失步"的假 bug。正确姿势：页面内轮询
`#heroNet[data-stage]` 到目标阶段并稳定 700ms+，同帧读 caption/圆点/光环属性
作 DOM 铁证，必要时同上下文调 `miniNet.stop()` 冻结后再截图。视觉模型对小字号
caption 的读数不可全信，以 DOM 为准。

## 被否掉的备选

- **保留六视图导览、只调字号间距**——不解决"没有落点"的根因；
- **把四个指标全部做大**——又回到等权重墙；
- **动画放进数字带**——动的地方应该是"过程"（网络归并），不是"结论"（数字）。
